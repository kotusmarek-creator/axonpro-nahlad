Slovakia in Numbers

https://slovenskovcislach.sk

Project description:

The Slovakia in Numbers (Slovensko v číslach) project aims to collect various data scattered across the internet and public administration sources and to present it in a clear, accessible form to internet users, businesses, the scientific community, students and foreign nationals. The “Slovakia in Numbers” project focuses on analysing open public-administration datasets relating to Slovakia, obtained from a variety of sources such as public authorities, government agencies and non-profit organisations. The project aims to provide an overview of various aspects of Slovak society, the economy, the environment and more through numerical data and visual presentations. It combines text and numerical processing with visual presentation of data using charts and maps. The results of the analysis can be used to gain a better understanding of different aspects of Slovak society and thus help to address a range of public-administration challenges.

The “Slovakia in Numbers” application (hereinafter the application or the portal) will collect data from a variety of sources. Data collection will be automated as far as possible, although semi-automated and manual data entry is also anticipated.

The data will be stored in a database, and an archive will be built at the same time so that time trends and archives can be created even for data that is not currently archived.

The graphical part of the application will display the data with a particular focus on breaking it down by individual territorial units, down to the level of municipalities or other trackable units where the data allows.

The data and outputs (graphs and tables) can be used in many other applications and publications.
